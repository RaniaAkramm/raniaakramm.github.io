What are gift codes?

Gift codes (also called redeem codes) are short strings you enter in Card Arise for a one-time reward on your account. The public code above grants gems and gold so you can summon, upgrade, and keep playing.

Mythic cards are not unlocked by a public all-Mythic gift code. You earn Mythic cards by collecting 200 pieces from watching ads.

How to redeem

  1. Update or install Card Arise 1.1.17+ (the current download is 1.1.25).
  2. Open the app and go to Account or Profile.
  3. Find the gift code / redeem code box.
  4. Enter ARISEGIFT and tap Redeem.

Each code works once per account.
